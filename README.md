# Linguini Holidays

A modern travel booking and tour discovery web application built for **Linguini Holidays Private Limited**. The platform provides a responsive, intuitive interface for exploring curated Himalayan expeditions and heritage weekend circuits, with direct customer inquiry workflows.

- **Live Website:** [https://linguiniholidays.com](https://linguiniholidays.com)
- **Deployment:** Vercel

## Overview

- **Domain:** Travel & Tourism / E-commerce
- **Architecture:** Client-side Single Page Application (Vanilla JavaScript, HTML5, CSS3)
- **Design System:** Custom brand palette based on Deep Indigo (`#3C3884`) and Ivory (`#F2EFE8`)

## Key Features

- **Dynamic Tour Discovery:** In-browser search and multi-criteria filtering across destinations, tour duration, and price points.
- **Detailed Itinerary Views:** Modal overlays featuring comprehensive day-wise schedules, highlights, inclusions, and exclusions.
- **Lead Capture System:** Context-aware booking modal that pre-fills selected package details for customer callback inquiries.
- **Responsive Layout:** Optimized for mobile, tablet, and desktop viewports using CSS Grid and Flexbox.

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Typography & Icons:** Inter font, Font Awesome 6
- **Hosting & Infrastructure:** Vercel, GoDaddy DNS

## Local Setup

No package managers or build steps required.

```bash
# Clone the repository
git clone https://github.com/thisisanimesh01/linguini_holidays.git
cd linguini_holidays

# Serve locally
python3 -m http.server 8080
```

Open `http://localhost:8080` in your web browser.
